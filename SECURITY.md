# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Teleproto, please **do not open a public GitHub issue**.

Instead, please send an email directly to the maintainer or submit a Private Security Advisory on GitHub.

All security vulnerabilities will be promptly investigated and patched in a minor release.
